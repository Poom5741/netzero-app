# Implementation Plan: Match Shared Tokens, Dashboard Shell and Login Presentation

**Branch**: `003-shared-tokens-dashboard-shell-login` | **Date**: 2026-09-15 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/003-shared-tokens-dashboard-shell-login/spec.md`

## Summary

Align the NetZeroCarbon frontend CSS design tokens and dashboard shell presentation to match the extracted reference designs from `visual-qa-screenshots/admin-extracted/` and `visual-qa-screenshots/sponsor-extracted/`. This is purely a CSS/visual-parity task — no backend changes, no API changes, no data model changes. Three surfaces are in scope: Admin login, Admin dashboard shell, Sponsor login, and Sponsor dashboard shell. Work proceeds by surface in order: (1) measure actual values from extracted source files, (2) update `globals.css` and component tokens, (3) capture before/after evidence, (4) verify auth behavior is unchanged.

**Language/Version**: TypeScript (Next.js 16.3, React)

**Performance Goals**: Not applicable — CSS token changes do not affect runtime performance

- Auth mechanism must remain completely unchanged
- One bounded commit per surface per phase; no merge or deploy

**Scale/Scope**: 4 surfaces (Admin login, Admin shell, Sponsor login, Sponsor shell) × 3–5 viewports = 12–20 comparison points

## Execution Order (Per Surface Batch)

For each surface in order: Admin Login → Admin Shell → Sponsor Login → Sponsor Shell → LIFF Regression:

1. **Inspect**: Read current component file and `globals.css`
2. **Extract**: Measure actual token values from reference source file (colors, widths, radii, spacing)
3. **Compare**: Identify delta between current implementation and reference
4. **Update**: Change only the tokens that differ; remove decorative effects only where reference differs
5. **Capture**: Take before screenshot (current), apply change, take after screenshot
6. **Compare**: Run pixel comparison; document any remaining discrepancies
7. **Verify Auth**: Run auth quickstart scenario to confirm behavior unchanged
8. **Commit**: One bounded commit naming surface, changed files, and requirement IDs
