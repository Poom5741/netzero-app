# Quickstart: Shared Tokens, Dashboard Shell and Login

**Feature**: 003-shared-tokens-dashboard-shell-login

## Prerequisites

- `npm run dev:all` running (frontend on :3000, backend on :8787)
- Valid admin test credentials (`admin@netzerocarbon.com` / test password in `tests/poc1-verification/`)
- Valid sponsor test credentials (CPA code `CPA-001`, test password)
- Playwright installed (`npx playwright install --with-deps chromium`)
- Reference captures from `tests/visual/captures/reference/` (generated by spec 005 harness)
- Viewports available: 1280×720, 1440×900, 390×844, 360×844

### S2: Admin Login — Auth Behavior Unchanged

```bash
# 1. POST invalid credentials → verify Thai error appears
curl -X POST https://netzero-carbon-poc.poom-a1d.workers.dev/login \
  -d "email=bad@test.com&password=wrong" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -c /tmp/admin-cookies.txt \
  -w "%{http_code}" -o /dev/null -s
# Expected: error message in Thai in response

# 2. POST valid credentials → verify session cookie set and redirect
curl -X POST https://netzero-carbon-poc.poom-a1d.workers.dev/login \
  -d "email=admin@test.com&password=test" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -c /tmp/admin-cookies.txt \
  -w "%{http_code}" -o /dev/null -s
# Expected: 302 redirect

# 3. Access /admin with session cookie → verify dashboard loads
curl -b /tmp/admin-cookies.txt -w "%{http_code}" -o /dev/null -s \
  https://netzero-carbon-poc.poom-a1d.workers.dev/admin
# Expected: 200
```
