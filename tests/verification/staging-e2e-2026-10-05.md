### D-1 (defect, security-adjacent, moderate): sponsor logout does not terminate the session
- Repro (observed 2026-10-04 20:02–20:13Z):
  1. Login sponsor@netzero.com at /sponsor/login (cookie nzc_session set on BACKEND host netzero-carbon-poc.poom-a1d.workers.dev per F2 cross-origin contract).
  2. Click ออกจากระบบ in the portal header → redirected to /login (appears logged out).
  3. Navigate to /sponsor → full dashboard renders again (hard reload too). Observed ≥3s, no bounce.
  4. /sponsor/reports → EX-2042 download → a SECOND CSV lands with real data.
  5. GET https://netzero-carbon-poc.poom-a1d.workers.dev/session (browser, credentials included) → {"authenticated":true,"role":"sponsor","email":"sponsor@netzero.com"} — 10 minutes AFTER logout.
  6. Same check on frontend host /api/auth/session → {"authenticated":false} (frontend-host cookie absent/cleared).
- Expected (job spec J3): "logout → /sponsor now redirects to login; back button does not resurrect the session."
- Root cause (code, candidate 8125303): shared frontend/src/components/dashboard/dashboard-header.tsx logout calls same-origin POST /api/auth/logout, which clears nzc_session on the FRONTEND host only. The sponsor session cookie lives on the BACKEND host (cross-origin login). Backend POST /sponsor/logout (src/routes/sponsor.ts:134) DOES clear with correct SameSite=None mirroring — but the 017 header never calls it. Admin is unaffected: admin login is same-origin, so /api/auth/logout clears the right cookie (verified: /admin bounced to /admin/login after logout).
- Classification: defect (declared-scope J3 step failure; session survives user-visible logout until 24h TTL). Severity: moderate (CPA-safe data only, but authenticated surfaces remain accessible after explicit logout on a shared machine).
- Fix direction (for Dev): header logout must clear the cookie on the host that owns it — call `${NEXT_PUBLIC_API_BASE}/sponsor/logout` with credentials:"include" for sponsor (or a role-aware logout), keep same-origin /api/auth/logout for admin; consider Cache-Control: no-store on authenticated downloads as defense-in-depth.
- Note: gate itself is sound — after a TRUE logout (legacy backend portal POST /sponsor/logout), /sponsor bounced to /sponsor/login in <3s ✓, and direct GET /sponsor/reports/EX-2042/download unauthenticated → redirected to /login ✓.
