# Visual Comparison Report

This directory stores the output of `tests/visual/scripts/compare-pair.ts` runs that diff source-reference captures against implementation captures.

## Status

Captures have not yet been generated by the automated pipeline in this environment. The infrastructure to do so is in place:

- Source/reference renders: `tests/visual/lib/capture.ts`, `tests/visual/scripts/capture-single.ts`, `tests/visual/scripts/capture-all-screens.ts`
- Comparison: `tests/visual/scripts/compare-pair.ts` with `tests/visual/lib/compare.ts`
- Provenance: `tests/visual/lib/provenance.ts` writing to `tests/visual/captures/provenance/`

## How to run

1. Start the application dev servers so that implementation routes are reachable.
2. Use `capture-single.ts` with `captureKind=source-reference` against the Claude artifact HTML bundles.
3. Use `capture-single.ts` with `captureKind=implementation` against the running application routes.
4. Run `compare-pair.ts` for each route/viewport pair.
5. Capture results and reports are written here.

## Mismatches

None recorded yet. Any future mismatch must be documented here with:

- Surface and route label
- Source artifact ID and source module
- Viewport and state
- Capture filenames for source and implementation
- Source hash values
- Brief explanation of the expected cause
